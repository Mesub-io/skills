## 0.1.0

The foundation, with no skill yet.

- `catalog.yaml` as the single source of truth, with the seven planned skills.
- The mould of a skill folder, and `pnpm new-skill` to start one from it.
- `pnpm render`: the README blocks, `skills.sh.json`, each skill's hand-off block and the kit directory.
- `pnpm validate`, with a failing kit per rule, and CI on pull requests and on `main`.
- The eval file format.
